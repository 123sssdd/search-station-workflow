# 平台质量信号阈值参考表 v0（优化规划师，2026-10-29 00:53）
状态：初值，待 2 轮实测后校准；最终以本轮 standards/<domain>.md 为准。数值为经验起点，不是外部来源结论，引用时注明「v0 参考值」。

| 平台 | 信号 | 参考下限（v0） | 核验方式 | 备注 |
|---|---|---|---|---|
| GitHub | star | 教程/工具 ≥100；框架 ≥1k（按领域调整） | API stargazers_count | 新项目（<6 个月）可放宽并标注 |
| GitHub | 近 90 天提交 | ≥1 | API commits?since= | 0 次提交标「可能停更」 |
| GitHub | issue 响应 | 近 20 条 issue 中有维护者回复 ≥30% | issues API | 作口碑参考 |
| GitHub | license | 有明确许可证 | API license | 无许可证扣分 |
| 小红书 | 收藏 / 评论 | 待定 | 手动低频读 | 只作发现渠道；需追溯原始链接；遇风控即停 |
| SkillHub / clawhub | 页面真实性 | 标题匹配且页面 > 兜底页尺寸（约 65KB 为兜底页） | API + 标题核验 | 任意路径都返回 200，不能只看状态码 |
| SkillHub / clawhub | 下载量 / 评分 | 仅参考，不设门槛 | 站内数据 | 站内数据易刷 |
| B站 / 知乎 | 播放量 / 赞同 | 待定 | box 被拦 | 被拦就换来源并注明 |
| 论文 / 官方文档 | 发表方或官方来源 | 必须是官方域名或 arXiv/会议 | URL 域名 | 不设热度门槛 |
| 课程 / 博客 | 更新日期 | 热点 ≤3 个月；常规 ≤12 个月 | 页面日期 | 经典资料不限时间，但标年份 |
