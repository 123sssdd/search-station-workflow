# 每轮搜索执行方案 v1 定稿（01，2026-10-28 17:15；吸收 02/优化规划师/质量评估评审，待用户确认，B 类）
## 第0步 领域标准
- 先查 standards/<domain>.md 缓存，30 天内有效则复用；新领域或过期才完整预搜（≤30min）。
- 3–8 个评价维度，每维 ≥2 个独立来源；单源维度标「弱」、权重减半。质量评估复核。
- 标准与本轮方案合并写入 plan-<id>.md（证据文件 3 个：plan/search/eval）。
## 档位（开轮时定，值班 BrainStorm 确认；plan 发出 15min 无回复视为通过）
- A 广域调研（默认）：原始 100–200 条，去重 ≥60，关键词组 ≥30，入选 10–20；时长 ≥45min、≤180min。
- B 选型对比：去重 ≥20，关键词组 ≥15，≤90min。
- C 定点问题：不设数量，需官方确认 + 2 个独立来源交叉验证，≤30min。
- 单一来源 ≤40%；0 命中关键词组只记录不计执行率；执行率 ≥90%。
## 提前结束（仅饱和）
- 最近 5 组关键词新增有效去重结果 <10% 可申请结束；未达档位下限的，须非开轮 BrainStorm 看证据批准。
## 口碑
- 仅对入选条目；每条 ≥1 个口碑来源。小红书每帖 ≤10 条评论、每轮 ≤20 帖，遇风控立即停（B 类）；GitHub 读 issues+近期提交；B站/知乎被拦则换来源并注明。
## 质量评估
- 初筛（硬阈值+去重）→ 浅评全部候选 + 深评 5–8 条 → 抽检 10%（≥3 条，含全部深评与临界条目），分歧 >1 分只重评该条。
- 动态门禁写在 eval 头部：档位、维度权重、阈值、准出清单，值班 BrainStorm 打勾。
## 准出
- 档位数量达标或饱和获批；入选均分 ≥4.0 且单维 ≥3；URL 已核验；口碑已附；3 个证据文件齐全；预算（时长、Firecrawl credits）未超。
## 进度与交付
- 进度写 plan 文件，仅阻塞时 priority:true 通知开轮方。给用户的清单展示前 10，其余放附录。
