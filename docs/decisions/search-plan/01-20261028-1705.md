# 每轮搜索执行方案模板 v0（01 草案 2026-10-28 17:05）
没有方案不开搜。Searcher 填写 rounds/plan-<id>.md，值班 BrainStorm 确认后执行。

## 第 0 步：领域标准预搜（每轮必做，约 15–30 分钟）
- 按本轮任务所属领域，搜索业内评价标准：权威榜单、评测基准、选型指南、专家 checklist、社区共识。
- 产出 standards-<id>.md：列出 3–8 条该领域的评价维度、权重和阈值，每条附来源 URL。
- 质量评估复核这份标准后，据此生成本轮的评分表和准出门槛（动态门禁）。

## 第 1 步：方案（由第 0 步推导，以下为默认值，可按领域调整）
- 量：原始候选 100–200 条，去重后 ≥ 60 条，精评 ≥ 30 条，入选 10–20 条；单一来源占比 ≤ 40%。不达下限不准结束。
- 关键词矩阵 ≥ 30 组：核心词 × 同义词 × 中英文 × 场景词（教程、实战、开源、对比、踩坑、面试），外加平台专用词，记录每组的命中数。
- 时间段：按领域更新速度定。默认近 12 个月；热点取近 3 个月；经典资料不限时间，但要标注年份。
- 质量信号：用第 0 步得出的阈值，比如 star、收藏、点赞、评分、维护活跃度。
- 评论区：每条入选结果抽读前 20 条评论，总结口碑、常见坑、是否过时。
- 领域与类型：至少覆盖 3 种类型（教程、开源、工具或 skill、课程、论文、案例）。

## 第 2 步：质量评估（3 轮）
- 第 1 轮：初筛，按硬阈值和去重。
- 第 2 轮：精评，按第 0 步的维度逐条打分。
- 第 3 轮：值班 BrainStorm 抽检 20%，分歧超过 1 分时回到第 2 轮重评。

## 第 3 步：准出门槛（动态部分来自第 0 步，固定部分如下）
- 数量达标，关键词执行率 ≥ 90%。
- 每条入选结果都有已核验可访问的 URL，并附口碑总结。
- 文件齐全：standards、plan、search、eval 四个文件。

## 时长
- 单轮不少于 45 分钟（不含第 0 步）；每 30 分钟汇报一次进度（条数和覆盖率）。
