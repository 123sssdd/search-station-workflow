# 02 评审：开源可扩展性方案（对象：优化规划师-1808.md）
评审：Brainstorm 02；时间：2026-10-28 18:23 UTC+8；范围：全面评审
总体：同意方向。P1–P3 都属 B 类，等用户决定。下面有 4 处必须修改。

1. 目录约定 — **同意**。修改：说明和现有仓库 /workspace/search-station-workflow（templates/、docs/）之间的迁移关系，避免出现两套目录。
2. 角色模板 7 节、I/O 只通过文件 — **同意**。修改：再加第 8 节「写入权限」，写明谁可以写哪个存储，把「归档角色唯一写入、Todos 写 Todos 库」做成协议级规则。
3. 搜索后端可插拔 — **修改**：discovery_only 不要默认给小红书。v2 现行规则是：找 skill 时小红书是优先渠道，结论用原始链接核实。改法：discovery_only 做成按平台的可选项，示例配置里小红书写成 `discovery_only: false, verify_with_origin: true`。另外，每个后端增加 `credits_ref_limit`（参考上限，不阻断），和 v2.1 保持一致。
4. 存储可替换 — **同意**。修改：Todos 库不由 manifest 派生，要单独写一个「tasks 适配器」（notion / local-sqlite），否则和「Todos 唯一写入 Todos 库」的规则对不上。
5. station.yaml — **同意**。修改：必须包含以下字段：user_language: zh（面向用户的消息语言）、rotation: odd→coordinator_a / even→coordinator_b、night_window 加 A/B 分类清单、score_scale: 5 与门槛（均分 4.0 / 单维 3）。.env.example 里只写变量名。
6. 平台无关的纯文本指令 — **同意**。
7. 版本号与 CHANGELOG — **同意**。CHANGELOG 由 Memory 唯一写入，和优化清单第 13 条合并，不要两处各写一份。
8. 分步落地 — **同意**，但顺序要改：P1 先出 schemas（manifest 的 url 字段要求可核验），再出 station.yaml，因为校验脚本依赖 schemas。每一步推送仓库都属 B 类，夜间不推。

补充：开源前要做一次脱敏扫描（token、cookie、个人链接、Notion 页面 ID），这一步属 A 类；对外公开属 B 类。
